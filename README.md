# ねこ手帳アプリ

## 概要  
猫の体調や日常の出来事を記録できる、**シンプルで可愛いヘルスケア記録アプリ**です。  
1日ごとのタイムライン形式で記録を表示し、カレンダーで過去の記録も振り返ることができます。

---

## 使用技術  
- SwiftUI  
- MVVMアーキテクチャ  
- CoreData  
- カスタムフォント / カスタムカラー   
- タイマー処理  
- NavigationStack  
- モーダル表示

---

## 主な機能  
- 猫ちゃんの登録・選択  
- 「おしっこ」「ごはん」などカテゴリ別の記録登録  
- 詳細入力（テキスト入力）機能  
- カレンダーから記録の閲覧  
- 日記機能（自由記述）  
- タイムライン表示（1日分）  
- データの保存・削除（CoreData使用）  
- 設定画面（開発者メッセージなど）

---

## 工夫ポイント  
- 1日ごとの記録管理：記録1件ごとにCoreDataで保存、日付で絞り込み表示  
- デザイン性の工夫：明るい色とグラデーションでポップにペットアプリ感を、オリジナルフォントで統一感を演出  
- UIの一貫性：全画面共通の背景スタイル、タブやモーダルを活用したわかりやすい導線  
- 保存期間制限：1年以上前の記録は自動削除するロジックを導入し、快適性を創出

---

## 苦労ポイント  
- CoreDataのデータ取得・保存処理（特に日付のフィルタ処理）  
- 画面遷移後のデータの持ち回り（selectedCatIDなど）  
- モーダルとナビゲーションの使い分けと切り替え  
- 「タイムラインに表示されない」などの保存バグの修正  
- 記録カテゴリごとの細かい条件分岐とViewの制御

---

## ビルド方法  
- Xcode 16.0以降  
- このリポジトリを clone  
- `cat_health_app.xcodeproj` を開いてビルド＆実行  
- 実機でもシミュレーターでも動作確認済
